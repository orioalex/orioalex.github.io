台大資工系大三下修課心得

Cell
2026-06-13
修課心得
台大, 心得

這學期有點失算，原本覺得上學期太累了，打算這學期以甜涼課為主，順便救一下炸掉的 GPA。
原本有選上 blender 和 Unreal Engine 的課，猶豫之後還是怕 loading 太重所以退了，有點可惜。
但結果各個課的 loading 都比我預期的要高，導致最後還是變成了又累又炸 GPA 的一個學期。

因為我覺得我沒有很認真在課堂上，所以就單純用文字敘述來說明我覺得的甜涼度吧。

必修課程

人工智慧導論 - 陳尚澤、陳縕儂教授（3 學分）

  • 分類：必修
  • 成績：
  • 甜涼度：
    +
  • 課後時間：
    • 作業：
      • 手寫作業：2 小時 / 份，
      • 程式作業：自從發現 AI 寫的比我還高分之後我就丟給 AI 寫了
    • 期中段考：3 小時
    • 期末 project：3 小時

評分方式

作業 10% * 4 份、期中考試 30%、期末 project 30%
還有一個演講心得，但不確定算分算到哪裡。

上課方式 & 作業

前半學期是陳尚澤教授，主要偏向於演算法而沒有機器學習的部分。
像是 A star、Q learning、貝式定理等等。
作業和實作也是和 DSA 差不多的感覺，但比 DSA 簡單。
另外作業的標準答案可以在網路上找到，可能是因為這樣所以幾乎大家都滿分，結果我自己寫的版本吃爆 TLE 被扣了 20 幾分。

後半學期是陳縕儂教授，比較著重在機器學習的數學層面，主要就是微積分和線性代數。
手寫作業就是單純的數學題，有時候也會有證明題。
程式作業就是把這些數學式子實作成 python 語法。

作業本身不難，期末 project 給分也很寬鬆，從 cool 看起來大部分的人都拿滿分。

期中期末

期中和作業差不多感覺，沒有太活的題目，不過題目計算量偏多，貝式定理的部分有點麻煩。

今年的期末 project 是做「誰是牛頭王」而不是原本的德洲撲克，我的策略是算每一張手牌的扣分期望值，選出扣分最少的牌打出，結果過了大部分的 baseline 但輸給了大部分的同學。
聽別人說他們是用暴力往下算的方式，但我不確定他們怎麼在不知道其他玩家手牌的情況下算的，我自己做出來的結果也不好。

感想

一開始就預想這堂是甜涼課，整體確實 loading 也不重。
課程內容也如一開始預想，偏向大雜燴，什麼都沾一點但又沒有深入。
然後過了一個學期結果我還是不會機器學習的 python 語法，之後可能要找個時間學一下了。

  • 分類：必修二選一
  • 成績：B
  • 甜度：
    • 聽別人講是不算甜但也沒有特別不甜
  • loading：以必修來講不重
  • 課後時間：
    • 每週作業：3 小時 / 份
      • 每週 loading 落差很大
    • 期中、期末段考：各約 1.5 小時
    • 期末 project：約 6 小時
      • 但我們這組的 project 是失敗的，應該要花更多時間才對

評分方式

期中考 40%、期末考 60%，其他的作業也必須要完成，但計分不明。

我還是不懂我怎麼就拿 B 了，我應該沒有那麼慘吧。
等等第比例出來再看看。

上課方式

這門課和上學期的互動裝置自造與發明很像，硬要說的話這堂課的面向更廣一點。

每週會有教授本人的授課和助教主講的 lab。
教授的授課偏向於介紹各種裝置，有時候也會介紹它們的原理或是特性。
授課的範圍從機械結構、電路裝置、各種感應器、tuning 、程式和數學之類都有。

lab 作業

助教的 lab 主要是講解作業的先備知識，教學內容會跟據每次的作業而有不同，這學期主要是以 arduino 和 unity 居多。
lab 是四人一組，但絕大部分的 lab 都需要實體到學新 523 才能做，所以也不好平行處理。
我們這組是有空的人自主做並更新進度給其他三個人，下一個有空的人再往下做。

有時候運氣好的話下課後照著助教的簡報做一做就可以解決掉 lab 了。

段考

期中和期末的段考會考教授和助教的上課內容，因為上課內容很廣，所以出題範圍也很廣，感覺什麼都有可能出。
debug 題、原理、數學、函式參數、電路、實作等等都有。
我找不到考古題，段考的時候被打了個措手不及。

期末 project

期末 project 是要做一艘可以自動走迷宮的船，不可以遙控。
有三個 subtask，走直線、走一圈、走迷宮。
最後只有一組成功完成走迷宮的 task。

原本以為這沒有很難，畫好電路圖之後就想說應該快好了，沒想到真正的麻煩現在才開始。
我們這一組做的時候一直出問題，像是升壓版不知道故障了幾次、做到一半發現腳位不夠、麵包版太大連帶船體也太大超過尺寸限制、下水的時候發現船浮不起來、臨時加了氣球結果變得轉彎會卡到。
總之處理了各種問題之後，到了要下水前突然短路，結果修好的時候已經來不及測試了。
不確定學期成績炸掉是不是因為這樣。

感想

當初會選這門課而不是計網實，一方面是我跟計系實的教授比較熟，另一方面是覺得上學期修過互動裝置自造與發明之後再來修這堂課應該會比較有優勢，而且我覺得做東西的課比較有趣。
從現在來看，這些考量也確實沒有錯，我確實覺得這堂課很好玩。
以一門必修來講，loading 也比預期的輕，上課的時候也可以做自己的事，唯一一個不滿大概只有段考吧。
也感謝我的組員們，大家都會在有空的時候自主做 lab，也沒有人計較自己付出的多寡。

選修課程

計算機圖形 - 歐陽明教授（3 學分）

  • 分類：系上選修
  • 成績：A-
  • 甜度：我也不知道
    • 我覺得我的付出偏少，有 A- 應該還行吧
  • loading：
    • 期末 project 和作業的 loading 偏重，但給分算高
  • 課後時間：
    • 作業：20 小時 * 1 份
    • 期末 project：約 3 小時
      • 理論上應該需要 20 小時以上

評分方式

作業 1、期中考、期末 project 各三分之一。
期末的 oral presentation 排名前二分之一的人可以加分，排名越前面加越多分，最高加 5 分。

上課方式

雖然是 9:10 的課，但 9:30 才開始上課，且網站上有 2024 的課程錄影，教授也說早上起不來的話可以看錄影就好。
雖然我這學期幾乎沒有去上課，但我還是覺得這堂課是需要實體出席的。

原因之一是這堂課發不發公告取決於助教，教授本人不會發公告，因此像是關於 oral presentation 的期望和詳細規定、期中考的閱卷時間等等由教授操刀的部分就常常沒有公告。
另一點是這堂課的 ntucool 和教學網站似乎從來沒有整理過，2021 到 2026 的檔案全部放在一起，再加上也沒有分類、檔名年份有時候也不對，沒有去上課的話完全不會知道教到哪裡、甚至不會知道哪些是今年的檔案。
再加上這門課有三個網站，ntucool、助教的課程網站、以及教授的個人網站，但三者的更新的不同步的，常常發生看完了考試說明才發現是 2024 的公告等等的情況。

以這次作業一為例，作業一要參照 CV2026_HW1_TA.pdf，但 CV2026_HW1_TA.pdf 裡面又 refer 了一份 ICG_hw1_spec.pdf（2025 的 spec），而這份 spec 使用了 ICG_2024_HW1.zip 和 ICG_HW1_2024_v2.zip。
更麻煩的是，兩份 spec 對於作業的繳交格式是衝突的，後來我乾脆直接兩種格式都交了。

  • 在 2026 的期末 project 出現的 2025 slide，而且據我所知，今年完全沒有用到這個。

但其實只要實體出席的話就不會有這些問題了。
我自己覺得教授的上課步調穩定，講解也很清楚，再來一次的話我會選擇實體去上課。

作業

這門課只有在上半學期中間的這一次作業。
作業是用 webGL 實作各種 shading 以及各種矩陣變換，像是旋轉、縮放、平移等等。
概念本身不難，但大部分人應該是第一次接觸 webGL，或甚至是第一次寫 javascript，再加上 webGL 本身是非常低階的圖形渲染，所以學習成本蠻高的。
因為教授說他會問實作細節，所以不太能完全仰賴 AI，我是照著這個 tutorial 學怎麼寫的。

期中

期中考規定不能上網，可以使用電子器材或是紙本。
就規定來說 local AI 是沒有違規的，考試當下看起來也有不少同學在用，不過我自己覺得這不是教授的本意所以就沒有用了。
聽同學說教授知道這件事之後直接在課堂上開罵，但我當時不在場，不確定這是不是真的。

可能是因應 AI 工具的普及，段考中也加入了一些非知識性的內容，像是「從下列選項中選出符合我們上課的 AI 使用規範的選項」。
總之我完全不知道，最後考了 71，還錯過了閱卷時間。

期末

期末是要做一個 project，主題可以自己選或是從教授提供的主題來做，但一定要有論文支撐。
但也有人同時合併好幾篇 paper，做出一個強大的專案。也有人 oral presentation 時講了超級厲害的目標，我也不知道最後有沒有做到。但似乎有幾個人還真的做出來了。
我自己因為當初規劃課表時沒有預期到這個 loading 導致時間不夠，最後單純就找一篇偏簡單的 paper 照做一次而已，沒想到最後有 87 分，意外地高。

心得

原本看以前的心得文，以為是一堂可以線上跟課、沒有什麼 loading 的課。所以沒有安排太多的時間給它。
結果實際上雖然平常不會有什麼 loading，但在作業一和期末 project 時會有大量的 loading 集中，實務上這堂課也不適合線上上。
總之因為自己的判斷失誤導致留下不太好的修課體驗，對於一堂自己有興趣且授課優良的課有點可惜。

評分方式

上課方式

前半學期主要在教 TouchDesigner，後半學期以聲音相關的軟體為主，但後半的部分我沒有聽得很懂。

TouchDesigner 是互動作品常用的軟體，可以把一個影像套用各種效果器後再輸出。
前半的 TouchDesigner 會帶學生做幾個比較簡單的小作品，像是偵測畫面移動、fade in fade out、場景切換等等的小專案。

期中期末

期中和期末 project 差不多。
會在科教館展示小組的作品，這堂課著動於互動，所以我們的作品會需要有「玩家」或是「參與者」。
期末 project 則更進一步，希望我們的作品能有劇情，作一個 12~15 分鐘的作品。

我期中的時候主要負責 TouchDesigner 本身，我們這一組做的是類東方彈幕遊戲，但玩家需要真的動身體來躲子彈。
雖然自己講怪怪的，但我真的蠻喜歡這個作品的。

感想

剛好上學期修過沉浸式科技劇場專題實作，那堂課也是使用 Arena + TouchDesigner。
但不同的是那堂課著重在 Arena，而這堂課著重在 TouchDesigner。

原本上學期的一個遺憾就是沒能學會 TouchDesigner，所以期初聽到教授說這堂課用 Arena + TouchDesigner，而且會偏向 TouchDesigner 之後就鐵了心一定要修這堂課了。
結果也如我所願，學會了怎麼用 TouchDesigner，學期末還順便練了 blender。
下學期如果可以的話也會想修修看這個教授的聲音系列的課。

專題研究 - 鄧善元教授（2 學分）

  • 分類：系內選修
  • 成績：A+
  • 甜度：？
  • loading：不輕，不算是可以水的專題
  • 課後時間：
    • 每週實驗室的 meeting：每週約 1.5 小時
    • 個人 meeting：每週約 1 小時
    • 做專題的時間：每週約 2 小時

評分方式

不確定。

上課方式

整體蠻自由的，沒有要求要做到什麼程度。
每週有一次整個實驗室的 meeting，和一次和教授的個人 meeting。
整個實驗室的 meeting 主要是和其他人分享自己的專題方向，以及這週的進度。

這個實驗室是做人機互動，從軟體到機械都有。
共同的大方向是「利用某些方法來強化 / 補足人類現有的不足」。
這個實驗室常見的方法像是透過 VR / AR、機械裝置（外骨骼）、或是利用震動、電刺激、聲音等等來達成目標。

有時候也會有像是一般上課的部分，教授會講一些做研究需要知道的東西，像是論文的編排、示意圖的做法、實際測試的流程、有效研究的要件等等。

在做專題的過程中也可能會發現不可行之後換新主題，我和其他幾個專題生也換了好幾次。
目前我的主題是「將力氣較強肌肉的力氣轉移到另一個」，不過這個是學期末才換的主題，還沒有什麼進展。

感想

我修了那麼多專題，每次都是剛修專題的時候覺得很有趣，但過了一陣子之後就變得不喜歡了。
原本覺得可能只是我不喜歡這個領域，但換了好幾個專題之後還是這樣，即使是原本覺得有趣的主題也會隨著專題的進行而失去樂趣，那表示我不喜歡的不是研究主題，而是「研究」本身吧。

即然這樣的話就沒有必要拘泥於自己的興趣，找一個符合末來規劃的專題做下去就對了。
所以才會上學期剛說完自己不會走這個領域，結果下學期就又來修專題了。
主要是覺得做實體東西比較有趣，再加上自己也有在考慮日本讀碩，日本的資工主要還是以機器人和 AI 相關為主，所以這個實驗室的主題也符合末來的規劃。
目前也不打算換了，應該是會持續待到畢業吧。

日本文化下 - 田世民教授（2 學分）

  • 分類：系外選修（日文系必修）
  • 成績：A
  • 甜度：
    • 應該是蠻甜的
  • loading：輕（資工標準）
  • 課後時間：
    • 期中期末段考：各約 2 小時

評分方式

好像沒有公佈，我猜有計分的有上課唸課文、點名、期中期末考

上課方式

整體和上學期差不多，這邊應該不會寫太多，詳細可以看這篇。

這學期更著重在日本的文化上，像是文學和哲學等等的層面。
但我自己覺得各個方面都太淺，只能算是有提到，而沒有真的去講內部的內容，這部分有點可惜。
像是裡面提到了各個時代有名的文學做品，但上完之後我還是只是知道有這個作品的存在，具體是講什麼內容，或是因應什麼時代思想而生，這些內容就沒什麼提及。

期中期末

因為考前會劃重點，所以這次有特別把劃記處記熟。
有一些挖空題會把太明顯的提示拿掉，不確定教授是不是特意做的。
但總之我考得還算是可以吧。

感想

這學期沒什麼太多的感想，也算是當了一回假日文系吧。
也確實知道了很多以前不知道的文化知識，未來有機會去日本的時候可以去深挖一下相關的歷史。
這一年的知識就先放在腦袋的一角吧，搞不好哪一天會用上。

日本文學名著選讀下 - 洪瑟君教授（2 學分）

  • 分類：系外選修
  • 成績：C
  • 甜度：
    • 應該不甜，但我文學不好所以不準
  • loading：輕（資工標準）
  • 課後時間：
    • 期中期末段考：各約 2 小時

評分方式

有期中和期末考、有 cool 上的小組作業和上課時的小組討論發表，和上課點人唸課文。
具體有哪些計分不確定。

上課方式 & 內容

會選一些文學作品，先讓學生唸一段後再用中文講一次。
這學期最主要是夢十夜、羅生門，還有一些其他的作品。
遇到比較難的單字、片語或是文法會加以說明。

文章開始之前會先講作者的生平，以及作品的時代背景。
文章結束之後會讓小組討論作品的意涵，然後教授再做更深的說明。

期中

有單字和片語的形音義題，會從上課講過的出。
然後也會考其他上課講過的東西，像是作者生平、比喻或是修辭法、文學意涵、象徵或是特色等等。

感想

原本這堂課不在修課計劃之內，但開學第一週突然發現我只差這堂和下學期的一門課就可以拿到文學的領域專長，而且這堂課剛好我有空堂。
拿 C 算是完全出乎當時的預料之外，看來我真的不會文學。

初級韓文（二） - 洪攸善教授（2 學分）

  • 分類：系外選修
  • 成績：A
  • 甜度：
    • 很甜，沒意外應該是穩 A+ 的
  • loading：輕（資工標準）
  • 課後時間：
    • 期中期末段考：各約 2 小時

評分方式

小考 6 次 * 每次 5 分。
還有作業和出席分，但不確定比例是多少。
除非完全不可抗力事件，不然只要缺席就會扣分，包含病假和第一週的缺席也會扣分。

上課方式

會先帶著唸一次課本的單字，再來講文法，然後再帶著同學唸課文和課本習題。
作業是每一課的課本文法練習。
教完一課的隔週會有小考，主要考單字和文法，有背好的話應該可以拿滿分。
沒有段考，期中和期末考週不上課。

這個教授偏向於口說層面，上課時偏好用問答的方式授課。
教授是韓國人，我自己覺得他的文法教得不是很好懂，一方面可能是他的中文不太流利導致說明上的困難，再加上他似乎為了要把文法解釋清楚而嘗試說明背後的脈絡，原本可能是「A -> A’」的文法會被解釋成「A -> A1 -> A2 -> A3 -> A’」，反而變得不好理解。

感想

我自己覺得這堂課的授課方式不適合我，我自己喜歡「單字 -> 文法 -> 課文 / 練習」的學習順序，這樣我在學習課文、或是做練習的時候就不會卡在單字上面了。
上個學期教授的教法是在上這一課的同時先考下一課單字，所以我在面對新的一課的時候已經了解了裡面的單字，在學習上比較順暢。而且課本的練習會出成作業，也是讓我加深對文法和單字的印象。
但這個學期的教授是完整教完一個才考試，所以我通常到考試前才背單字，導致上課文和練習的時候我其實不太懂句子本身的意思，加上這些練習只有課堂上帶唸，所以我通常很快就忘了。

但說到底只要我事前先背好單字 + 課後自主練習就沒有問題了。
啊不是啊我那麼勤勞的話我早就自己唸了

總結

心得

要進入大學最後一年了，有點意外。
回過神來就發現自己從新人變老屁股了，也確實有時會不經意地發現，雖然總是覺得自己還什麼都不會，但其實這三年來無形中學習了不少知識，而不再是大一那種什麼都不會的狀態了。

整體的心得跟上學期差不多吧。
沒什麼特別想修的課了，大四應該會以語言檢定和研究所申請為主，同時把缺的課補一補而已。
目前覺得 HCI 蠻好玩的，應該會走 HCI 研究室吧。

要說遺憾的話可能是沒有戀人和社交圈極小吧。
但硬要說的話我確實對各種交際活動提不起興趣，有這種結果算是預期中吧。

多語言社感覺很好玩，可惜沒能入社，下學期再申請一次看看好了。
還有目前在考慮要不要創一個 Vocaloid 社，但我不擅長辦活動，還是算了吧。

後記

這學期已經有意識地降低了修課學分，也沒有接助教了，但感覺 loading 比上學期還重。
我猜是因為這學期沒有像是前瞻資訊科技這種可以上課偷寫作業的課，而且人工智慧導論和計算機圖形又被我拿去睡覺，導致我需要不少課後時間來處理。
看來下次選課的時候也要注意選一些可以降 loading 的課。
